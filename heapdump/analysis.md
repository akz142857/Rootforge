## Method notes

Shallow sizes, instance counts, holder attribution and thread stacks are exact per-object statistics. Retained sizes come from a Lengauer-Tarjan dominator tree over the full reference graph rooted at a virtual node joined to every GC root; they are exact for the graph as recorded, but a dump only records strong references, so objects kept alive solely through soft/weak/phantom references appear reachable here.
